# Source Code and Reproducibility Materials

The [complete package](https://github.com/Haoshaopeng/ELB-KAN-PINNs/releases/download/data-v1.0.0/ELB-KAN-PINNs.zip) contains model weights, partitions, experimental records, verification results and eight HDF5 field files. Extract the package and follow its README. The original third-party wake reference is retrieved separately.

The repository includes per-run test errors and a field index. The 114 supplementary wake validations are not independent tests.
